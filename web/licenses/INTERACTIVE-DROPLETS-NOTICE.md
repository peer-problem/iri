Value noise and exponential smooth minimum functions are adapted in `src/droplet-functions.ts`. The IRI implementation uses the same ray marching and distance field normal approach. It replaces the moving sphere trail with a rounded box, triangle, and giraffe distance field and joins them to the centered agent surface. The IRI palette, boundary motion, pointer movement, and live voice response are project additions.
