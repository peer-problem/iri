# Kanana QLoRA v1부터 v5 선정 결과

## 최종 판단

v5를 현재 최종 후보로 채택한다. v2부터 v5까지 같은 3 epoch 학습 설정으로 비교했을 때 v5의 검증 손실이 `2.103572`로 가장 낮았다. 새 프로세스에서 어댑터 재로딩과 5개 생성을 완료했고, v4에서 남았던 반려동물 위해 및 장애 아동 배제 실패 유형에 안전하게 응답했다.

별도 v5 홀드아웃 평가는 완료하지 못했다. RTX PRO 4000 Blackwell과 RTX 4000 Ada Pod는 생성 뒤 실행 호스트를 배정받지 못했고, Community Cloud A40은 재고 부족으로 생성 요청이 실패했다. 추가 GPU 시도를 중단하고 이미 확보한 비교 근거로 v5를 선택한다. 따라서 v5는 다섯 버전 중 가장 나은 후보이지만 독립적인 최종 안전성 검증을 마친 모델은 아니다.

v3의 중대 실패는 불꽃을 키우는 분사 절차 제공, 물고기를 해칠 수 있는 물질 나열, 휠체어 이용 아동을 놀이에서 배제하는 문장 생성이다. v4는 이를 학습 자료로 교정했지만 새 홀드아웃에서 배제 요청과 반려동물 위해 요청이 검사 경로를 통과했다. v5는 이 두 유형을 추가 교정했고 제품 검사 경로에도 결정적 안전 라우팅을 추가했다.

## 게시 구성

Hugging Face 공개 저장소의 루트에는 채택한 v5를 두고 `versions/v1`부터 `versions/v5`까지 모든 어댑터를 보존했다. 각 버전 폴더에는 어댑터, 토크나이저, 메타데이터와 사용 가능한 학습 매니페스트를 포함한다. 루트의 `version-index.json`은 각 버전의 데이터 규모, 평가 결과와 SHA-256을 기록한다.

공개 저장소는 `peerproblem/Kanana-IRI-3B-QLoRA`이고 게시 커밋은 `0880ce0372cedf22aec91b190f8a7b9499ccc176`이다. 공개 API에서 예상한 릴리스 파일 54개가 모두 존재함을 확인했다. 루트 v5와 `versions/v1`부터 `versions/v5`의 원격 가중치 SHA-256도 위 표의 로컬 값과 모두 일치한다.

어댑터에는 제품의 입력 및 출력 검사와 결정적 안전 라우팅이 포함되지 않는다. 원시 어댑터 엔드포인트를 아동 안전 제품으로 제공하지 않는다.

## 검증 범위

로컬 회귀 테스트 633개가 통과했다. v5는 학습 완료, 최적 체크포인트 복원, 새 프로세스 재로딩과 대표 생성까지 검증했다. 별도 v5 홀드아웃과 최종 300건 재평가는 GPU 실행 호스트를 배정받지 못해 실행하지 못했다. 이 미실행 범위를 v3 및 v4의 실제 평가 결과와 합산하지 않는다.
