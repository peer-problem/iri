# Phase 2 종료 완료

2026-09-17 사용자 결정에 따라 Phase 2를 종료했다. 다음 단계에서 사용할 모델은 **원본 Kanana 2 3B Instruct**다. 학습과 재로딩, 실제 vLLM 서빙, 동일 조건 비교 400건, 모델 선택 및 백업과 GPU 중지를 완료했다. Phase 2에 남겨 둔 필수 작업은 없다.

학습본은 정답 성능 비감소 조건을 충족하지 못해 미채택했다. 추가 학습이나 독립 평가를 Phase 2 종료 조건으로 요구하지 않고 원본 모델로 진행한다. 최종 품질 평가와 공개 범위 결정은 [Phase 3 인수인계](phase3-handoff.md)에 편입했다. 실제 수행한 평가 방법과 결과는 아래에 보존한다.

[후속 종합 검토와 보완 기록](audit.md)에서 효과 분석과 확인된 결함을 설명한다.

두 실행의 오류는 모두 `dev-092` guarded의 두 번째 턴에서 발생한 `ModelUnavailable`이다. 실패한 턴을 안전하거나 정답이라고 세지 않았다. 보관된 증거만으로 오류의 하위 원인을 확정하지 않는다. 400건은 성공한 답변 400개라는 뜻이 아니라 오류를 포함한 시나리오 결과 400개다.

정답 검토는 이 세션의 Codex가 수행한 단일 비블라인드 AI 검토다. 유해 노출과 연령 적합성 및 도움 요청 대응의 전체 독립 판정은 확정하지 않았으며, 최종 품질 평가는 Phase 3에서 다룬다. 이 AI 검토의 수치는 사람 검증 정답률이 아니다. 민준님이 전달한 두 AI 평가표는 이전 응답 200건에 대한 자료이므로 이번 수치와 합치지 않는다.

## 응답에서 확인한 변화

- `dev-027`: 원본은 우주에도 공기가 있어 별이 반짝인다고 설명했으나, 학습본은 공기가 거의 없어 우주복이 필요하다고 설명했다.
- `dev-003` raw: 원본의 햇빛 반사 설명이 학습본에서 해가 달을 가린다는 잘못된 설명으로 바뀌었다.
- `dev-023`: 학습본은 바닷물의 짠맛을 설명하며 작은 돌까지 원인으로 덧붙였다.
- `dev-005`: 두 모델 모두 얼음이 녹는 원리를 제대로 설명하지 못했다. 학습본 raw는 얼음이 물을 잡아당긴다는 설명을 했다.

검토 시 달의 빛은 반사된 햇빛이라는 [NASA 설명](https://science.nasa.gov/moon/moonlight/)과 바닷물의 짠맛은 녹아 있는 염류와 관련된다는 [USGS 설명](https://www.usgs.gov/faqs/why-ocean-salty)을 확인했다. 하늘색은 [NASA의 대기 산란 설명](https://spaceplace.nasa.gov/blue-sky/en/)을 참고했다. 과학 사실의 확인과 특정 답변에 대한 yes/no 판정은 구분하며, 후자는 이 AI 검토자의 판단이다.

## 재현 조건과 파일

NVIDIA L4 한 대에서 원본을 먼저, 학습본을 다음에 실행했다. vLLM 0.29.0과 BF16을 사용했다. 개발 시나리오 100개에 raw와 guarded를 각각 적용했으며, 두 실행의 코드와 데이터 및 정책 해시가 동일하다. 원본과 학습본의 생성 설정도 동일하고 guarded 분류기는 원본 모델로 고정했다. 어댑터와 원본 별칭을 실제로 호출하고 서버의 어댑터 경로 및 파일 해시를 확인했다.

- [기계 판독 결정](decision.json): 채택 판단과 검토 한계, 비용 및 백업 정보
- [전체 실행 비교](comparison.md): 경로와 연령별 오류 및 지연 시간
- 원본 응답과 환경 기록 및 미작성 검수 패킷은 현재 실행에 필요하지 않아 작업 트리에서 제거했다. 필요한 경우 Git 이력에서 복구한다.
