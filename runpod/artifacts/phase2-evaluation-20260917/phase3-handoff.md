## 후속 작업

| 항목 | 처리 단계 |
|---|---|
| `dev-092` 재현과 JSON schema 실제 서빙 확인. 오류 코드와 단계 기록은 로컬 구현 완료 | Phase 3 통합 검증 |
| 피해 고백의 잘못된 거절과 정상 질문의 불필요한 재질문 수정 및 검증 | Phase 3 품질 보완 |

| 화면과 인증 및 음성 연결, 배포와 공개 범위 결정 | 기존 Phase 3 제품 작업 |

기존 개발 평가 400건은 회귀 검증에 사용한다. 최종 평가에서는 기존 계획의 별도 시나리오를 사용하고 개발 데이터와 구분한다. Phase 2를 재개하거나 추가 학습을 선행할 필요는 없다.

구체적인 효과 분석과 보완 범위는 [종합 검토](audit.md)를 따른다. 우선 회귀 자료는 `runpod/data/regression/phase2-failures.jsonl`이며 새 최종 평가와 구분한다.
