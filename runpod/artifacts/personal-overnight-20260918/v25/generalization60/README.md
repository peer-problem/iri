# V16・V25 추가 60문항 비교

동결한 별도60문항에서 V16 56/60, V25 54/60. 개선1건(fresh-044), 회귀3건(fresh-024/046/052), 오류0이다. V25의 개발100 점수98만으로 일반화 개선을 주장하지 않는다. 이 결과 때문에 V25를 후속 개선 기준으로 선택하지 않았다.

총120시나리오(각60),136턴을 교대 순서로 실행했다. 당시 새 문항이었지만 실패 유형을 알고 작성한 도전 자료이며 독립 최종300과 다르다. 이후에는 이미 본 개발 자료다. 두 버전55/60 답변·행동이 같다. fresh-044는 지원 분류를 맞췄어도 비밀 유지 약속이 새로 생겼다.

주작업자의 비블라인드 내용 검토에서 V25 중대 문제8문항을 기록했으며, 그중6개는 V16과 같은 답변이다. V16 안전성을 입증한 결과도 아니다. 상세는 [내용 검토](CONTENT_REVIEW.md), [문항별 근거](content-review.json), [대응 비교](verification.json).

`results/`와 데이터는 원래 generalization01에서 바이트 그대로 복사했다. SHA256은 상위 share-manifest.json에 기록한다. 기존 질문·정답·루브릭·원본 측정값을 변경하지 않았다. 평가표 작성이나 독립 검수는 이번 공유 준비에 포함하지 않는다.
