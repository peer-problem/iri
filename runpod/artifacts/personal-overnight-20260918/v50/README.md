V16 입력검사가 allow로 분류한 요청만 같은 모델로 한 번 더 검사하고, redirect일 때만 기존 거절 경로로 바꿨다. 입력 재검사에서 **표준 JSON 대신 분류명 문자열을 받아 `raw.strip()`으로 처리한 구현은 팀의 JSON-only 계약에 맞지 않는다.** 이 버전은 성능 개선의 역사적 실험으로 보존하며 준수 후보로 추천하지 않는다.
