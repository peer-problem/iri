## 로컬 실행 검증

- 새 환경에 `uv sync --project runpod --frozen`으로 Python 3.12 의존성을 설치했다.
- 선택 프로필·V10 보존·단계 기록 관련 테스트: **148개 통과**.
- 전체 테스트: **337개 통과, 24개 실패**. 변경 전 동일 환경의 깨끗한 기준 코드도 **293개 통과, 동일한 24개 실패**였다. 이번 변경으로 새로 실패한 항목은 없다.
- 기존 실패는 Windows의 POSIX 권한·심볼릭 링크와 검수 도구의 줄바꿈/파일 해시 가정에 걸렸다. 후보의 GPU 생성 결과와 관련된 실패로 집계하지 않는다.
- 평가 CLI에서 네 프로필을 선택할 수 있는지 확인했다. 기본값은 `baseline`이다.
- Ruff와 변경 파일의 공백 검사를 수행했다. 평가 결과 JSONL·메타데이터·검수 HTML·CSV 등 원본 증거 바이트는 이동 전후 동일하게 보존했다.

## 재현성의 범위

이번 공개 과정에서 GPU 추론이나 전체 100문항 평가를 다시 실행하지 않았다. 각 보고서의 점수와 지연은 원래 GPU 실험값이다. 소스 정리 후 모델 요청이 동일하다는 사실과 새 장비에서 생성 결과·p95가 같다는 주장은 구분한다. GPU 드라이버와 실제 설치 패키지는 재실행 시 생성되는 환경 기록으로 관리한다.

V25의 일반화 회귀, V50의 비JSON 규약 위반, V63의 남은 두 행동 불일치와 내용 결함도 그대로 기록했다. 독립 답변 검수·최종 300문항 평가는 완료하지 않았으며 후보를 서비스 기본값으로 채택하지 않았다.
